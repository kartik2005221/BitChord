<h2 align="center">What's New</h2>

> **Unofficial fork release (ktk).** This build carries the **v1.9.1** application code from [BitChord-Desktop-Revived](https://github.com/Bntagaaa/BitChord-Desktop-Revived) with the fork changes below. It follows upstream's release numbering, so it is tagged **v1.9.4.1** — it does **not** yet include upstream's 1.9.2 features.

1. 🗂️ **(NEW) Downloaded playlists get their own tab:** The **Downloads** page now carries a **Playlists tab** of its own — **Songs · Playlists · Artists · Albums** — where every downloaded collection stands as a full, scrollable page of its own instead of a section squeezed above the songs. Each row keeps its cover, its billing line, and its progress ("12 of 15 downloading", "available offline"), and each record's menu still opens it, updates it, or removes the download. Local Music keeps its three tabs — the fourth belongs to Downloads alone.
2. 📥 **Everything v1.9.4 carried:** Downloads keep the **whole playlist** — cover, title, and a full snapshot of its songs in the order the page lists them, the way BitChord Android has always done it. A song is never fetched twice, and removing a record releases only the files nothing else holds.
3. 🔄 **Update a downloaded playlist when it moves:** When a downloaded playlist's live listing no longer matches its snapshot, the record is marked **update available** — the row says so, and updating merges the fresh listing in front of what the record once held, fetching only the songs not already on disk.
4. 📡 **A downloaded page opens even when the network will not:** A playlist or album the network refuses to fetch falls back to its downloaded copy, and every song in hand plays straight from disk while the rest stream when the connection returns.
5. 🔁 **(UNCHANGED) Everything before it:** the frosted covers, the Replay with its artists and its genres, the fork's own update channel and built-in Last.fm scrobbling, and upstream's v1.9.1 feature set — all still here.

<h2 align="center">Installation</h2>

**🐧 Linux**

- Download the available Linux package or AppImage.
- For AppImage, make the file executable before launching it.
