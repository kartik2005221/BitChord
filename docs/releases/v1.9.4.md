<h2 align="center">What's New</h2>

> **Unofficial fork release (ktk).** This build carries the **v1.9.1** application code from [BitChord-Desktop-Revived](https://github.com/Bntagaaa/BitChord-Desktop-Revived) with the fork changes below. It follows upstream's release numbering, so it is tagged **v1.9.4** — it does **not** yet include upstream's 1.9.2 features.

1. 📥 **(NEW) Downloads keep the whole playlist:** **Download all** on a playlist or album now makes the **collection itself** live in **Downloads** — cover, title, and a full snapshot of its songs in the order the page lists them, the way BitChord Android has always done it. A new **Playlists** section stands above the songs; every record shows how far it has come ("12 of 15 downloading", "available offline"), a spinning ring while files are in flight, and each record's menu can **open** it, **update** it, or **remove the download**. A song is never fetched twice — shared between two records or saved on its own, its file is kept, and removing a record releases only the files nothing else holds.
2. 🔄 **(NEW) Update a downloaded playlist when it moves:** When a downloaded playlist's live listing no longer matches its snapshot — songs added, removed, or reordered — the record is marked **update available**. The Downloads row says so, the playlist's overflow menu offers **Update download**, and updating merges the fresh listing in front of what the record once held, fetching only the songs not already on disk. Nothing is probed in the background; the mark is earned by actually seeing the listing again.
3. 📡 **(IMPROVED) A downloaded page opens even when the network will not:** A playlist or album the network refuses to fetch falls back to its downloaded copy — the page stands with its own songs, and every song in hand plays straight from disk while the rest stream when the connection returns.
4. 🛜 **(IMPROVED) Long playlists download whole:** The download follows a long listing to its last page before it asks for anything, so a collection of 843 songs is asked for as 843 songs — not the few hundred that had rendered when the menu was opened.
5. 🔁 **(UNCHANGED) Everything before it:** the frosted covers, the Replay with its artists and its genres, the fork's own update channel and built-in Last.fm scrobbling, and upstream's v1.9.1 feature set — all still here.
