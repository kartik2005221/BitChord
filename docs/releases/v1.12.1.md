# BitChord v1.12.1

This maintenance release improves song controls and downloaded playlist browsing.

## What's New

- Added Like and More options controls to the desktop mini player. The song menu provides the same actions as the full player.
- Updated song Like controls to use a thumbs-up icon, with distinct liked and unliked states.
- Fixed the Downloads Playlists tab so the Grid/List control switches between cover tiles and full-width rows.
- Improved the desktop mini player layout for narrower windows and side panels.

## Downloads

Choose the package for your operating system from the assets below. Linux packages are available as AppImage, DEB, and RPM. Windows packages are available as a setup executable, MSI installer, and portable ZIP.

A SHA256SUMS file is provided to verify the downloaded packages.
