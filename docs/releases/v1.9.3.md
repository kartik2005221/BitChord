<h2 align="center">What's New</h2>

> **Unofficial fork release (ktk).** This build carries the **v1.9.1** application code from [BitChord-Desktop-Revived](https://github.com/Bntagaaa/BitChord-Desktop-Revived) with the fork changes below. It follows upstream's release numbering, so it is tagged **v1.9.3** — it does **not** yet include upstream's 1.9.2 features.

1. 🫥 **(NEW) Blur album covers — privacy mode:** A new toggle in **Settings → Appearance** draws every album cover — rows, cards, search results, the queue and the player itself — through a deep blur under a soft scrim, so nobody glancing at your screen sees what you listen to. The look stays intentional (the player's own empty-state note shows through), motion artwork and video stills stand down while the mode is on, and Discord Rich Presence never sends your artwork outside the window in this mode.
2. 🎸 **(NEW) The Replay learns its artists:** The Replay's Top Artists chart now files collaborations under the lead artist — the way the charts rank — and each artist row carries the artist's own picture and page where one is found. A new **Top Genres** chart derives what kind of music you have been listening to from Last.fm's tags, artist name and nothing more, with a **Miscellaneous → Work out genres** toggle to turn the asks off. Everything learned is stored locally and keeps filling in as it is found.
3. 🎨 **(IMPROVED) The fork speaks in its own name:** README badges, download buttons and the app's own About links now point at **this repository**; the people who made BitChord what it is are credited up top — Kushagra Singh's original BitChord and Bntagaaa's BitChord-Desktop-Revived; and the original creator's donation button, funding file and housekeeping bots move out of this repository.
4. 🔁 **(UNCHANGED) v1.9.1 feature set + v1.9.2 fork changes:** Everything from upstream v1.9.1 (appearance customization, Spotify playlist import, local music artwork, AutoMix, …) and the fork's own v1.9.2 additions — built-in Last.fm scrobbling and the self-updating fork channel — are all still here.

<h2 align="center">Installation</h2>

Download the appropriate build for your operating system from the **Assets** section below.

**🪟 Windows**

- Download the available Windows installer or portable package.

**🐧 Linux**

- Download the available Linux package or AppImage.
- For AppImage, make the file executable before launching it.

> **Note:** This is an unofficial, community-maintained fork of [BitChord Desktop Revived](https://github.com/Bntagaaa/BitChord-Desktop-Revived), which is itself an independent fork of BitChord. For Android releases, please visit the [original BitChord repository](https://github.com/kushagrasinghx/BitChord).
