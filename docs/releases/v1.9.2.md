<h2 align="center">What's New</h2>

> **Unofficial fork release (ktk).** This build carries the **v1.9.1** application code from [BitChord-Desktop-Revived](https://github.com/Bntagaaa/BitChord-Desktop-Revived) with the fork changes below. It follows upstream's release numbering, so it is tagged **v1.9.2** — it does **not** yet include upstream's 1.9.2 features.

1. 🎫 **(NEW) Built-in Last.fm scrobbling:** The Last.fm API key and secret for this fork's own Last.fm application are bundled at build time, so Last.fm sign-in and scrobbling work out of the box.
2. 🔄 **(NEW) Fork update channel:** The in-app updater now checks **this repository's** releases instead of upstream, so updates install directly from here.
3. 📻 **(UNCHANGED) v1.9.1 feature set:** Everything from upstream v1.9.1 is here — appearance customization, Spotify playlist import, local music artwork, AutoMix, and more (see the [upstream v1.9.1 release notes](https://github.com/Bntagaaa/BitChord-Desktop-Revived/releases/tag/v1.9.1)).
4. 🛠️ **(IMPROVED) Release pipeline:** Last.fm credentials are injected through GitHub Actions secrets at build time and are never committed to the source tree.

<h2 align="center">Installation</h2>

Download the appropriate build for your operating system from the **Assets** section below.

**🪟 Windows**

- Download the available Windows installer or portable package.

**🐧 Linux**

- Download the available Linux package or AppImage.
- For AppImage, make the file executable before launching it.

> **Note:** This is an unofficial, community-maintained fork of [BitChord Desktop Revived](https://github.com/Bntagaaa/BitChord-Desktop-Revived), which is itself an independent fork of BitChord. For Android releases, please visit the [original BitChord repository](https://github.com/kushagrasinghx/BitChord).
