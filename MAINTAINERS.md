## About the original project

BitChord was created by Kushagra Singh ([@kushagrasinghx](https://github.com/kushagrasinghx)), who built the original Android client and its core architecture. The desktop lineage was carried forward by [BitChord-Desktop-Revived](https://github.com/Bntagaaa/BitChord-Desktop-Revived) by [@Bntagaaa](https://github.com/Bntagaaa) before this fork. The upstream original lives at [kushagrasinghx/BitChord](https://github.com/kushagrasinghx/BitChord).

## Responsibilities

Maintainers oversee project direction, repository maintenance, review and merging of contributions, and release management.
