## About the original project

BitChord was created by Kushagra Singh ([@kushagrasinghx](https://github.com/kushagrasinghx)), who built the original Android client and its core architecture. This fork continues the project as a desktop-focused client; the upstream original lives at [kushagrasinghx/BitChord](https://github.com/kushagrasinghx/BitChord).

## Responsibilities

Maintainers oversee project direction, repository maintenance, review and merging of contributions, and release management.
